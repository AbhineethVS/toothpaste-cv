# Demo Script

Use this as a 3 to 5 minute live demo runbook.

## 1. Open The Product

Open the live demo:

[https://toothpaste-cv.vercel.app/](https://toothpaste-cv.vercel.app/)

Explain the core idea:

> toothpaste.cv is a two-minute visual oral health screening tool. It helps users understand whether visible dental changes may need a dentist's review.

## 2. Show The Safety Boundary

Point out that the product is clear about what it is and what it is not.

- It is a visual screening tool.
- It is not a medical diagnosis.
- It does not replace a dentist.
- It cannot see under the surface like an X-ray.

## 3. Start Screening

Click **Start Screening**.

Show the five guided photo steps:

1. Front bite
2. Upper arch
3. Lower arch
4. Left side
5. Right side

Explain that each step gives framing instructions so photos are more consistent.

## 4. Generate The Report

Submit the five photos and wait for analysis.

Explain that the app checks nine visible screening categories:

- Crowding and alignment
- Tooth wear
- Discoloration and staining
- Gum health
- Plaque and tartar buildup
- Bite alignment
- Spacing and gaps
- Chips and fractures
- Possible decay

## 5. Walk Through Results

Show:

- Overall summary
- Finding severity
- Mouth-region context
- Photo evidence
- Plain next-step language

Explain that the result is written for a patient, not a clinician.

## 6. Export Or Save

Show the report export option.

If signed in, show that reports can be saved and compared later in the timeline.

## 7. Close

End with:

> toothpaste.cv does not diagnose dental disease. It gives users an earlier, clearer look at visible changes so they can decide when to ask a dentist.
